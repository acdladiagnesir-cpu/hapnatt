# Contribuer à HapNatt

Merci de votre intérêt. Toute aide est bienvenue : signaler un bug, proposer une amélioration, corriger la documentation, ajouter une traduction ou un exemple.

## Signaler un problème

Ouvrez un ticket (« Issue ») en indiquant :

- ce que vous avez fait, ce que vous attendiez et ce qui s'est passé ;
- le message d'erreur complet, s'il y en a un ;
- votre système (Windows, macOS, Linux) et votre version de Python ;
- si possible, un fichier `.dat` **avec des données fictives** qui reproduit le problème.

Ne joignez jamais de données confidentielles ou personnelles.

## Proposer une modification

1. Créez une branche à partir de `main`.
2. Gardez le style du code : noms en français, constantes de configuration en tête de fichier, scripts lançables depuis IDLE avec F5.
3. Vérifiez que les deux exemples (`Exemple_Simulation.dat`, `Exemple_Perimetres.dat`) se simulent sans erreur, en français et en anglais.
4. Ajoutez les nouveaux textes de l'interface dans `ppp_langues.py`.
5. Ouvrez une demande de fusion (« Pull Request ») qui explique le pourquoi du changement.

## Droits sur les contributions

Le projet est distribué sous licence GNU GPL v3 ou ultérieure. Pour que l'auteure puisse continuer à gérer la licence du projet, chaque contributeur signe, avant la première fusion, un accord de contribution qui lui cède ou lui concède les droits sur sa contribution. Votre contribution reste publique sous la GPL.

## Comportement

Toute participation est soumise au [code de conduite](CODE_OF_CONDUCT.md).

---

*English:* contributions are welcome. Open an issue with steps to reproduce and a `.dat` file with **fictitious data only**; keep the existing code style; check that both examples still run in French and English; add interface strings to `ppp_langues.py`. Contributors sign a contributor agreement before their first merge. All participation is subject to the Code of Conduct.
